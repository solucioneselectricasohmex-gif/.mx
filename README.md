\## 📋 Descripción



Sitio web de una sola página (SPA) con navegación tipo aplicación, desarrollado en HTML, CSS y JavaScript puro (sin frameworks ni dependencias de build).



\### Servicios ofrecidos



\- 🔌 \*\*Mantenimiento a media y alta tensión\*\* — Subestaciones y equipos eléctricos

\- ⚡ \*\*Instalaciones de baja tensión\*\* — Tableros, circuitos y canalizaciones

\- ☀️ \*\*Paneles solares fotovoltaicos\*\* — Diseño, instalación y mantenimiento

\- ❄️ \*\*Aire acondicionado\*\* — Instalación y mantenimiento preventivo



\---



\## 🚀 Características técnicas



\- ✅ \*\*SPA sin frameworks\*\* — Navegación entre secciones con JavaScript nativo

\- ✅ \*\*Diseño responsive\*\* — Adaptado a móvil, tablet y escritorio

\- ✅ \*\*Formulario → WhatsApp\*\* — Envío directo de cotizaciones

\- ✅ \*\*SEO básico\*\* — Meta tags, descripción y keywords

\- ✅ \*\*Accesibilidad\*\* — ARIA labels, navegación por teclado

\- ✅ \*\*Sin dependencias de build\*\* — Funciona directamente en cualquier hosting estático
